# ADR-003: Chosing AWS as the blogs cloud provider
## Status: Accepted (Date: 2026-28-9)
## Context
Currently the blog could only be distributed by taking the source repository onto a users local device. A cloud provider would enable us to be able to distribute it to a wider audience much more simply
## Decision
We chose AWS over alternatives such as Azure and GCP due to it's large volume of tools and free credits provided to allow this small project to run
## Consequences
- Positive: The potential of how the blog can be distributed grows immensely due to AWS's abundant tools
- Negative: The complexity of AWS will make be difficult to navigate and organise for us
